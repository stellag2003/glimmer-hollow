# Glimmer Hollow

Jogo de plataforma 2D em pixel art feito com HTML, CSS e JavaScript puro (Canvas 2D + Web Audio API).

## Como jogar
- ← → (ou A/D): mover
- Espaço / ↑ (ou W): pular
- Pise nos murklings por cima, colete glowdrops e chegue ao portal das 3 fases.

## Rodar localmente
Abra o `index.html` no navegador. Não precisa de build.
